## Long Description (HTML)

```html
<p><strong>EveryRow</strong> brings AI-powered data operations directly into Microsoft Excel. Process thousands of rows with natural language instructions - no formulas or code required.</p>

<h3>Features</h3>
<ul>
  <li><strong>Rank</strong> - Score and sort rows by qualitative criteria. "Rank companies by growth potential" or "Score leads by purchase intent"</li>
  <li><strong>Screen</strong> - Filter rows that match specific conditions. "Find companies in healthcare with 50+ employees" or "Keep only B2B SaaS startups"</li>
  <li><strong>Dedupe</strong> - Remove semantic duplicates intelligently. "Remove duplicate companies even with name variations" or "Dedupe contacts by email similarity"</li>
  <li><strong>Agent</strong> - Run AI-powered web research on each row. "Find each company's LinkedIn page" or "Look up founding year for each startup"</li>
  <li><strong>Merge</strong> - Join tables using AI-powered fuzzy matching. "Match customers to accounts by company name" or "Join datasets by similar product descriptions"</li>
</ul>

<h3>How It Works</h3>
<ol>
  <li>Get an API key at <a href="https://everyrow.io/api-key">everyrow.io/api-key</a> (starts with $20 free credit)</li>
  <li>Open the EveryRow task pane from the Home ribbon</li>
  <li>Enter your API key</li>
  <li>Select data in your spreadsheet (including headers)</li>
  <li>Choose an operation and describe what you want in natural language</li>
  <li>Results appear in a new worksheet</li>
</ol>

<h3>Use Cases</h3>
<ul>
  <li><strong>Sales Teams:</strong> Score and prioritize leads, enrich contact lists with research</li>
  <li><strong>Marketing:</strong> Clean and deduplicate campaign lists, segment audiences</li>
  <li><strong>Operations:</strong> Match and merge data from different systems</li>
  <li><strong>Research:</strong> Screen companies or contacts by complex criteria</li>
  <li><strong>Data Quality:</strong> Find and remove duplicates across large datasets</li>
</ul>

<h3>Pricing</h3>

</ul>
<p>Visit <a href="https://everyrow.io/pricing">everyrow.io/pricing</a> for detailed pricing examples.</p>

<h3>Requirements</h3>
<ul>
  <li>An EveryRow API key (free to get started)</li>
  <li>Excel 2016 or later (Windows, Mac, or Web)</li>
</ul>

<p><strong>Note:</strong> An EveryRow API key is required to use this add-in. Get your free API key at <a href="https://everyrow.io/api-key">everyrow.io/api-key</a>.</p>
```
